# Security policy

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub's **Report a vulnerability** button on this repository's Security tab, or by email to contact@joe-it-solutions.com. Include what you found, how to reproduce it and which version or commit you tested. We will acknowledge the report and keep you updated while we work on a fix.

In scope: the desktop app (including the preload bridge, process and file handling, and fix approval), the Firebase rules and Functions in `firebase/`, the account portal in `apps/website`, and the Flutter recorder package.
